개인정보처리방침

시행일: 2026년 11월 19일

배효진(이하 "운영자")는 DearLove 앱(이하 "서비스")을 이용하는 분의 개인정보를 소중히 여기며, 「개인정보 보호법」 등 관련 법령을 지킵니다. 이 방침은 서비스가 어떤 정보를 왜 수집하고, 어떻게 쓰고 보관하며, 언제 지우는지 설명합니다.

1. 수집하는 정보

구분항목수집 방법
계정로그인 서비스의 고유 식별자, 이름(또는 닉네임), 이메일 주소Apple·Google 로그인 시 사용자가 동의한 범위에서 제공받음
커플 연결연결 상대, 사귄 날사용자가 초대 코드로 연결하고 직접 입력
사용자가 남기는 내용일정(제목·날짜·시간·메모), 데이트 기록(제목·날짜·장소·메모·직접 만든 항목), 사진·동영상, 답장사용자가 직접 입력·첨부
자동 생성 정보접속 시각, IP 주소 등 서버 접속 기록, 오류 기록서비스 이용 중 자동 생성

서비스는 사진·동영상을 사용자가 직접 고른 것만 올리며, 기기의 다른 사진이나 연락처, 위치 정보를 읽지 않습니다.

2. 이용 목적

  • 회원 식별과 로그인, 커플 연결
  • 공유 캘린더·데이트 기록·편지·답장 등 서비스 기능 제공
  • 상대가 남긴 기록·일정의 알림 제공
  • 오류 확인, 부정 이용 방지 등 서비스 안정성 확보

3. 공개 범위

사용자가 남긴 일정·기록·사진·답장은 연결된 상대에게만 보입니다. 운영자는 이를 다른 사용자나 제3자에게 공개하거나 판매하지 않으며, 광고에 이용하지 않습니다.

4. 처리 위탁

수탁자위탁 업무
Supabase, Inc.데이터베이스·파일 저장, 인증 처리(데이터는 대한민국 서울 리전 서버에 저장)
Apple Inc., Google LLC로그인 인증

Supabase, Inc.는 미국 법인이며, 서비스 운영과 장애 대응 과정에서 데이터에 접근할 수 있습니다. 이 경우에도 위 이용 목적 범위에서만 처리됩니다.

5. 보관 기간과 파기

  • 정보는 회원 탈퇴 시까지 보관합니다.
  • 앱의 우리 > 회원 탈퇴를 하면 계정, 내가 만든 기록·일정·답장·사진, 내가 주고받은 편지가 즉시 지워지며 되돌릴 수 없습니다.
  • 연결 상대가 만든 기록은 상대의 계정에 그대로 남습니다.
  • 서버 접속 기록은 보안과 장애 대응을 위해 최대 90일 보관 후 지웁니다.

6. 이용자의 권리

이용자는 언제든 자신의 정보를 앱에서 확인·수정하고, 회원 탈퇴로 삭제할 수 있습니다. 열람·정정·삭제·처리정지 요청은 아래 연락처로 보내 주시면 지체 없이 처리합니다.

서비스는 만 14세 미만 아동을 대상으로 하지 않으며, 만 14세 미만의 가입을 받지 않습니다.

8. 안전성 확보 조치

데이터는 암호화된 통신(HTTPS)으로 주고받으며, 데이터베이스 접근 규칙으로 본인과 연결 상대만 자신의 데이터를 볼 수 있도록 제한합니다. 사진·동영상은 비공개 저장소에 두고 일정 시간만 유효한 주소로만 내려받을 수 있습니다.
